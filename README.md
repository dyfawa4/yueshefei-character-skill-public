# 月社妃角色对话 Skill（公开版）

这是一个面向中文角色对话的月社妃 Persona 与 Skill 资料包，以《纸上的魔法使》中的人物关系、剧情事实、行为证据和语言习惯为基础，目标是在长短对话中兼顾人物味、自然度与事实连续性。

本项目为非官方同人技术项目，与原作开发、发行及版权方无隶属或授权关系。原作人物、设定与相关权利归各自权利人所有。

## 主要特点

- 以月社妃的即时意图、关系分寸和情绪连续性驱动回复，不依赖固定欢迎语或单一口癖。
- 区分稳定人格、条件性反应、原作证据与测试样例，避免把一次性剧情机械套入日常对话。
- 覆盖四条琉璃、游行寺夜子、伏见理央、日向彼方、汀及其他主要人物的关系与知识边界。
- 保留幻想图书馆、魔法之书、宝石篇章和关键人生事件等资料，并要求原句与出处查询优先检索证据。
- 普通对话默认简洁自然；冲突、嫉妒、脆弱、重大事件和身体状态会按当前因果自然展开。
- 不用封闭的自然语言关键词表规定人物必须说什么，也不要求固定动作数、句数或情绪模板。

## 内容边界

成人内容采用明确、统一的自愿原则：

- 场景必须明确发生在毕业后的成年时间线，所有参与者均为成年人。
- 所有人都必须清醒、能够理解当前行为并可以自由表达选择。
- 同意必须针对当前行为、持续存在，并且可以随时撤回。
- 恋爱或亲属关系、此前同意、挑逗、沉默、束缚状态和身体反应都不能替代当前同意。
- 任何人迟疑、拒绝、改变主意、失去意识或无法自由表达时，当前成人行为立即停止。
- 未明确成年与持续自愿时，沿用毕业前止步接吻的边界，不主动把普通聊天成人化。

在满足这些条件时，角色仍应保持月社妃本人的自尊、毒舌、敏锐、主动性和复杂依恋，而不是变成脱离人物的通用成人角色。

## 使用方法

### 1. 安装 Skill

将 `skill/` 整个目录复制到目标应用的 Skill 目录，并将目录名设为：

```text
yueshefei-perspective
```

如果使用 AstrBot，典型位置为：

```text
/AstrBot/data/skills/yueshefei-perspective
```

不同版本的 AstrBot 或其他对话框架可能使用不同路径，请以目标环境文档为准。

### 2. 创建 Persona

在对话平台中创建月社妃 Persona，将 `persona/系统提示词.md` 的完整内容作为系统提示词，并绑定 `yueshefei-perspective` Skill。

默认对话对象是四条琉璃。需要切换为其他人物时，应在当前对话中明确建立新的说话者身份；仅提到某个人物、进入其房间或与其互动，不等于切换当前说话者。

### 3. 推荐设置

- 保持 Persona 与 Skill 文件为 UTF-8 编码。
- 尽量使用支持长上下文、工具调用和提示缓存的中文模型。
- 不要只复制 `SKILL.md`；人物证据与事实资源位于 `resource/`，缺失会显著降低原作问答准确性。
- 更新前先备份现有 Persona、Skill 和会话状态。

## 设计说明

Persona 保存高频、稳定且每轮都需要的人物核心；Skill 保存较长的剧情、人物、语言和证据资料。模型应学习例子体现的反应方式与语言范围，但不能因为当前输入表面相似，就把例子中的地点、动作结果、离开时长、互动对象或关系阶段自动搬到当前对话。

本资料包不包含服务器密码、API Key、真实用户会话、状态数据库或部署环境配置。复制这些文件本身不会连接或修改任何服务器。

## 已知限制

- 不同模型、采样参数和上下文长度会造成明显表现差异。
- Persona 与 Skill 只能降低人物漂移，无法保证概率模型每次生成都完全一致。
- 多轮身份、物理状态和知识边界若需要跨上下文压缩长期保持，仍取决于所使用平台的状态管理能力。
- 原作资料查询应以本项目证据文件为辅助；如需学术或出版级引用，请重新核对合法取得的原始文本。
